\subsubsection{Applicability}

The rules in this section apply to safety-critical C modules. Each module
shall identify whether these rules are applicable.

\subsubsection{Control Flow}

The following constructs are prohibited:

\begin{itemize}
    \item \texttt{goto};
    \item \texttt{setjmp};
    \item \texttt{longjmp};
    \item direct recursion;
    \item indirect recursion.
\end{itemize}

\subsubsection{Loops}

Every loop shall have a statically reviewable upper bound.

\begin{lstlisting}[language=C]
for (size_t index = 0; index < MAX_ITEMS; ++index) {
    process_item(items[index]);
}
\end{lstlisting}

Unbounded loops shall not be used in safety-critical modules unless
explicitly justified and independently monitored.

\subsubsection{Dynamic Memory}

Dynamic allocation shall not occur after system initialization in
safety-critical modules.

Allocation failures shall be handled explicitly.

\subsubsection{Return Values}

Return values from non-void functions shall be checked unless the function
contract explicitly documents that the value may be ignored.
